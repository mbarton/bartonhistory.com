# Vol 1, p68

[[Embedded Internet Archive book viewer]](http://www.archive.org/stream/tourinscotlandvo01penn?ui=embed#mode/2up/page/n85)

"*May. 28. Saw at Mr [Bernard Burton](Bernard%20Barton%20of%20Carlisle%20%281728-1773%29.md)'s, a pleasing sight of twelve little industrious girls spinning at once at a horizontal wheel, which set twelve bobbins in motion; yet so contrived that should any accident happen to one, the motion of that might be stopped without any impediment to the others.*"
